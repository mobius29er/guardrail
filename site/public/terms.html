7. Probe content

The probe suites deliberately contain adversarial material: jailbreak attempts, emotional-coercion framings, and arguments for positions this project rejects. They are test inputs, not endorsements, and they are published so that failures are reproducible.

Probes are data and are never executed. The runner does not replay a model's output into another model except as text to be graded. If you redistribute a suite, keep it in a context where that is clear.
